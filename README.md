# A Sojourner Tale

An interactive scrollytelling story narrated by the Sojourner rover, inspired by NASA's Mars Pathfinder mission and the style of "A Solar Tale".

Single-file site: plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally
Open `index.html` in any browser.

## Publish with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Your site will appear at `https://<your-username>.github.io/<repo-name>/`.

## Facts
Based on NASA's Mars Pathfinder mission. Please verify details at nasa.gov before using in teaching.
